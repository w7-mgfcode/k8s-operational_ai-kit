# A miniature hardening skill (fabricated)

## Phase 1: Scope lock
Write the state file from `assets/state-file.yaml`.

## Phase 2: Quick wins
Render the triage table from `assets/triage-table.md`. Deliver checkpoint A
with `assets/checkpoint.md`.

## Phase 3: Medium effort
Update the state file. Deliver checkpoint B with `assets/checkpoint.md`.

## Templates

| Template | Purpose |
|---|---|
| `assets/state-file.yaml` | Master sprint state |
| `assets/checkpoint.md` | Checkpoint delivery report |
| `assets/triage-table.md` | Benchmark triage table |
| `assets/workstream-brief.md` | Per-workstream summary for tracking |
