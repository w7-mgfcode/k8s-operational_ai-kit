# Terminology dictionary

The intake package's own dictionary, which ships beside the glossary.
(Fabricated.)

| Term | Meaning |
|------|---------|
| **role tag** | The playbook tag for a role, usually its directory name |
| **block-store** | Default storage class, 2 replicas |
| **secrets-store consumers** | About 20 applications that read runtime secrets |
| **encrypted vars** | The secrets file, loaded explicitly on every run |
| **edge controller** | Legacy ingress controller, being replaced |
