# The Contract

The single source of truth. Every rule this project has is stated here, once.
Delete any router and no rule is lost. Delete this file and there are no rules.

## Conventions

1. Every generated artifact MUST cite the file it was derived from.
2. Commits MUST follow `type(scope): description`.
3. Destructive operations MUST be dry-run before they are applied.
4. Scoped rules live in `rules/` and are indexed in `rules/README.md`.
